# 周邊記帳與揪團拆團小幫手 📦

專為動漫、偶像周邊自購記帳與揪團拆團設計的輕量級管理工具。

## ✨ 功能特色
- **個人自購管理**：支援商品圖片、單價數量試算、訂金/尾款追蹤、物流狀態。
- **揪團拆團/代購管理**：主團與角色認領樹狀清單、一鍵切換一補收款、二補循環狀態、自動差額試算。
- **財務看板**：即時 4 大 KPI 統計、自購通路圓環圖、揪團損益長條圖。
- **多端同步與備份**：支援 Firebase Realtime Database 雲端即時同步，並內建 JSON 匯出/匯入備份。

## 🚀 部署至 GitHub Pages
1. 將本專案所有檔案推送到 GitHub 儲存庫的 `main` 分支。
2. 進入儲存庫的 **Settings > Pages**。
3. 在 **Build and deployment** 下，Branch 選擇 `main`，目錄選擇 `/ (root)`，點擊 **Save**。
4. 等待 1~2 分鐘即可由生成的專屬網址存取！
